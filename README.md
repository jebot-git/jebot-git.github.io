# PLdot games

Published at https://jebot-git.github.io/ using GitHub Pages from `main` / root. No build step or JavaScript is required.

- `index.html`: two-game landing page.
- `ultimate-boomer-simulator/index.html`: original UBS page, using the shared template.
- `fpsloppa/index.html`: FPSloppa page, screenshots and short match clips.
- `style.css`: shared UBS-derived layout, typography and responsive styles.

Serve locally with `python3 -m http.server 8080` from this directory. Root-relative paths require serving the repository root. The old `/#environments` anchor links through to the UBS gallery. The separately hosted `/raifslop/privacy.html` privacy policy is unchanged.

UBS fishing/store media came from the game's stores branch. Captures use desktop game-engine rendering; headset visuals may differ. Font provenance and the original author licence are in `media/fonts/`.

FPSloppa media provenance and clip details are in `media/fpsloppa/README.md`. Videos load only on request and use native controls; there is no autoplay or tracking. Download links point to public GitHub releases.
