# Ultimate Boomer Simulator landing page

Published at https://jebot-git.github.io/ using GitHub Pages.

The minigolf update uses course previews rendered from the EOS-based main game branch. Twelve waters each have an 18-hole course. Fishing, BBQ and minigolf share the location.

The page is maintained directly in index.html. Original fishing/store media came from the stores branch; minigolf captures come from tools/render_minigolf_gallery.gd. Captures use desktop game-engine rendering with simplified preview water; headset visuals may differ. CC0 font provenance and the original author licence are in media/fonts/.
