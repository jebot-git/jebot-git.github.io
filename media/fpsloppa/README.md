# FPSloppa website media

Actual desktop engine captures and recorded spectator gameplay from the FPSloppa project, prepared 2026-10-09. No generated promotional imagery.

Screenshots: 1600×900 WebP derivatives of the map gallery renders.

- `santorini.webp`: `test-results/map-gallery/de_varq_santorini/04-spawn-1.png`.
- `magenta.webp`: `test-results/arena-gallery/dm_q30_magenta/06-spawn-3.png`.
- `iceridge.webp`: `test-results/map-gallery/ctf_t2_iceridge/04-base-0.png`.
- `dungeon.webp`: `test-results/koth-gallery/koth_ut_dungeon/04-spawn-1.png`.
- `abattoir.webp`: `test-results/arena-gallery/dm_q30_abattoir/05-spawn-2.png`.
- `broadside.webp`: `test-results/map-gallery/ctf_t2_broadside/04-base-1.png`.

Clips: 1280×720, H.264/AAC MP4 with fast start, 14 seconds each. Sources are `test-results/de-shoulder-recordings/de_varq_{map}/de_varq_{map}-5v5.mp4`: Santorini 00:55–01:09; Dust2 00:25–00:39. Posters come from each excerpt's first frame. Audio contains gameplay effects, with no narration. Clips were captured during expansion development.

Original community-map and asset authors retain their credits; see https://github.com/jebot-git/FPSloppa/blob/main/ASSET_CREDITS.md and https://github.com/jebot-git/FPSloppa/blob/main/docs/FINAL-EXPANSION.md.
